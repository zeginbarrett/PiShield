# Changelog

## 1.0.1
- Fixed errors when running local analysis, changing defense settings, or managing rules.
- Defense buttons now show the selected mode and pending changes.
- Added an updater that backs up changed web files without restarting DNS.

## 1.0.0
- Combined the installation steps into a single installer.
- Redesigned the dashboard and phone navigation.
- Added DNS history charts and system checks.
- Included previous fixes to reports, branding, and page layout.
- Added local Ollama and remote access instructions.
- New installations start in observation mode until additional threat feeds are enabled.

The full fresh-install sequence still needs testing on a separate physical Pi.
